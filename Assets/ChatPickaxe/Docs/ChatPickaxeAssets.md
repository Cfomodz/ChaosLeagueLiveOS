# Chat Pickaxe Assets

This mini-game uses runtime-generated placeholder sprites. Replace them with
pixel art assets listed below for final polish.

## Required pixel art assets

1. **Pickaxe sprite (16x16)**  
   Main falling object. Clear silhouette with a bright blade and wood handle.

2. **Ore block sprite (16x16)**  
   Mineable tiles that sit in the grid. Provide a rocky texture and a highlight.

3. **Background tile (16x16, tileable)**  
   Dark mine wall pattern to sit behind the grid.

4. **UI panel sprite (9-slice, low-res)**  
   Frame for the score and command text.

5. **Pixel font (bitmap)**  
   Low-res font for the score and chat overlay.

## Optional polish assets

- **Bedrock tile (16x16)** for the bottom boundary.
- **Spark/impact sprite (8x8)** for mining hits.
- **Arrow icons (8x8)** for left/right/drop reminders.
- **Sound effects**: spawn, move, hit, miss.
- **Short 8-bit loop** for background music.
